Politique de confidentialité

Dernière mise à jour : avril 2025

Awabi est une application Android d'apprentissage du japonais. Elle affiche une bulle flottante qui analyse le texte visible à l'écran, identifie du vocabulaire japonais, et permet d'exporter des cartes vers Anki.

Cette politique décrit précisément quelles données sont traitées, où elles transitent, et pourquoi.

Données traitées

LOCALContenu de l'écran

Quand vous tapez sur la bulle, l'app capture une image de l'écran et en extrait le texte via ML Kit Text Recognition (traitement entièrement sur l'appareil, sans connexion réseau). Ce contenu n'est ni stocké ni transmis, sauf si vous utilisez la fonction d'analyse grammaticale (voir ci-dessous).

LOCALProgression et vocabulaire

Les mots consultés, leur nombre d'apparitions, et votre deck Anki en cours sont stockés localement dans une base de données SQLite sur l'appareil. Ces données ne quittent jamais votre téléphone.

LOCALClef API

Si vous configurez une clef API pour l'analyse grammaticale (OpenAI, Anthropic, etc.), celle-ci est stockée localement dans les préférences de l'application (SharedPreferences). Elle n'est jamais transmise à nos serveurs.

EXTERNERequêtes dictionnaire — Jisho.org

Lorsque l'app analyse l'écran et qu'un mot japonais n'est pas trouvé dans le dictionnaire local (JMdict, bundlé dans l'app), une requête est envoyée à l'API publique de jisho.org. Cette requête contient uniquement le mot japonais recherché (ex : 食べる). Aucun identifiant personnel n'est transmis.

OPTIONNELAnalyse grammaticale — LLM tiers

La fonction "Analyser" est entièrement optionnelle et requiert que vous fournissiez votre propre clef API. Quand vous l'activez manuellement, le texte brut extrait de l'écran est envoyé au fournisseur LLM que vous avez choisi :

Permissions utilisées

Permission Utilisation
SYSTEM_ALERT_WINDOW Affichage de la bulle flottante par-dessus les autres applications
FOREGROUND_SERVICE
FOREGROUND_SERVICE_SPECIAL_USE		 Maintien de la bulle active même quand l'app n'est pas au premier plan
FOREGROUND_SERVICE_MEDIA_PROJECTION Capture d'écran via MediaProjection pour l'OCR. Demandée explicitement à l'utilisateur au moment de l'activation.
INTERNET Requêtes vers Jisho.org (fallback dictionnaire) et vers le fournisseur LLM choisi (optionnel)
POST_NOTIFICATIONS Notification persistante requise par Android pour les services en avant-plan
VIBRATE Retour haptique lors de l'ajout d'un mot au deck (appui long)
Service d'accessibilité Lecture du texte des vues Android visibles à l'écran (fallback si l'OCR n'est pas disponible). Utilisé uniquement pour extraire du texte en japonais, jamais pour lire des mots de passe ou des champs sensibles.

Le service d'accessibilité et la capture d'écran sont utilisés uniquement pour extraire du vocabulaire japonais affiché à l'écran. Ces données sont traitées localement et ne sont jamais transmises sans action explicite de votre part.

Ce que l'application ne fait pas

  • Aucune collecte de données analytiques ou de télémétrie
  • Aucun tracking publicitaire
  • Aucun compte utilisateur, aucune inscription
  • Aucun envoi de données vers des serveurs Awabi (il n'en existe pas)
  • Aucun accès aux contacts, à la localisation, à la caméra, au microphone ou au stockage privé
  • Aucun partage de données avec des tiers, hormis les services optionnels listés ci-dessus

Services tiers

ML Kit Text Recognition (Google)

Utilisé pour l'OCR japonais. Fonctionne entièrement sur l'appareil. Selon la documentation Google : "On-device APIs process data locally, and because the data doesn't leave the device, these APIs don't require you to have connectivity or send any data to Google."

JMdict

Dictionnaire japonais-anglais open source, intégré directement dans l'application sous forme de base SQLite. Aucune requête réseau. Licence : Creative Commons Attribution-ShareAlike 4.0.

Jisho.org

API dictionnaire publique utilisée en fallback pour les mots absents du dictionnaire local. Seuls les tokens japonais recherchés sont transmis. Politique de confidentialité de Jisho : jisho.org/about.

Vos données, vos droits

Toutes les données générées par Awabi (progression, deck courant) sont stockées localement sur votre appareil. Vous pouvez les supprimer à tout moment en désinstallant l'application ou en effaçant les données de l'app depuis les paramètres Android.

Awabi ne disposant d'aucun serveur ni compte utilisateur, il n'existe pas de données à demander, corriger ou supprimer de notre côté.
